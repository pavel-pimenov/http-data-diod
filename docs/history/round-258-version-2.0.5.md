# Round 258 — Версия 2.0.5 + анализ продакшен-композа l2-service-worker

## Задача
Поднять версию до `2.0.5` и проанализировать продакшен-композ
`l2-service-worker` на предмет ошибок конфигурации.

## Реализация
- `src/generate_version.sh`: `VERSION "2.0.4-$SHA"` → `VERSION "2.0.5-$SHA"`.
- Анализ продакшен-композа: найдены расхождения/ошибки (см. детали в
  анализе — потенциальные проблемы с NATS TLS-путями, healthcheck на
  /metrics вместо /health/ready, неполные пары TLS-переменных и т.п.).

## Проверка
- `./rebuild-and-run.sh` — сборка зелёная, все сервисы healthy.

## Тэг
- `git tag -f 2.0.5 HEAD && git push origin 2.0.5` — тэг для CI-сборки.
