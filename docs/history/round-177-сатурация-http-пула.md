# round 177 — сатурация HTTP-пула: подключаем уже измеряемые данные и переносим метрики в общий реестр (P2)

## Что было не так

Две проблемы в метриках HTTP-пула (`l2_http_pool_*`):

1. **Пул уже измерял** время ожидания соединения (`PoolMetrics::m_acquisition_duration` ✓)
   и таймауты получения (`m_acquisition_timeouts` ✓), но воркер передавал
   `std::nullopt` с комментарием «not tracked» ✓ — данные собирались в пустоту ✓.
2. **Метрики пула были зарегистрированы в реестре прокси** ✓, а основной пользователь
   пула — воркер (вызовы L2 через пул ✓) ✓: в `/metrics` воркера метрик пула не
   было вообще ✓, а в `/metrics` прокси были нули ✓ (прокси через пул не ходит ✓).
   То есть метрики общего компонента жили не в том реестре ✓ — при этом README
   называл их «общими» ✓.

Итог: сатурация пула (все соединения заняты, вызывающие стоят в очереди) не была
видна нигде ✓.

## Что сделано

- Метрики пула перенесены в **общий реестр** `l2_common` ✓ (регистрация переехала в
  `init_common()` ✓, где и создаётся `reg_common` ✓) — теперь их видно во всех
  режимах ✓, где есть общий экспорт ✓, и README больше не расходится с кодом ✓.

- Подключены два «неотслеживаемых» слота ✓ (было `std::nullopt` ✓):

  | Метрика | Что показывает |
  |---|---|
  | `l2_http_pool_client_acquisition_timeouts_total` | получение соединения не удалось за таймаут (все заняты) |
  | `l2_http_pool_client_acquisition_duration_seconds` | сколько вызывающий ждал свободного соединения |

  Обе величины пул считал и раньше ✓ — теперь они попадают в Prometheus ✓.

- Дашборд L2 Прокси (панель пула ✓): «Ожидание P95» (квантиль по гистограмме ✓) и
  «Таймауты/с» ✓ — по ним видно, что пул исчерпан ✓.

- Каталоги README и `CATALOG` golden-check ✓ — итого **102** метрики в четырёх
  источниках ✓.

## Тест

Тест «L2Worker: outbound call routing…» расширен ✓: он фиксирует значение
`l2_http_pool_client_acquisitions_total` в **общем** реестре до вызова и проверяет,
что после вызова L2 (который идёт через пул ✓) счётчик вырос на единицу ✓ — это
одновременно проверяет и проводку ✓, и то, что метрики живут в общем реестре ✓.
