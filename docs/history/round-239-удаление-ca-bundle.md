# Round 239 — Удалён пустой ca-bundle.crt

## Задача
В корне репозитория лежал файл `ca-bundle.crt` размером 0 байт. Он нигде не
используется (не в docker-compose, не в коде, не в .env). Был случайно добавлен
в коммите `ab1ec78` ("feat(observability)") и забыт. Ранее аналогичный пустой
файл уже удалялся (см. archive-pre-round-24.md).

## Реализация
- `git rm ca-bundle.crt` — удалён пустой файл.
- `*.crt` уже в `src/.dockerignore` (строка 46) — файл и так не попадал в
  Docker-образ.

## Проверка
- Файл нигде не referenced (grep по docker-compose/.env/code — пусто).
- Удаление не влияет на сборку (файл не используется).
