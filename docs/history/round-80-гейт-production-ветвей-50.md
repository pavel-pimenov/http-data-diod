## Изменение

`--exclude '/app/.*test_[^/]*\.cpp$'`) подняла порог:

```dockerfile

```

— стал жёстче: теперь любой жирный PR в production-путях (логи, редкие
ветки таймаутов/реконнектов) без сопутствующих тестов валит coverage-стадию.

  должен ронять стадию на пустом месте.
