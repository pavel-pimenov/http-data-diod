## Наблюдения

- **~13 GB** — большой объём, преимущественно сервисы fipc-*, ws-publisher, mes-sender.
- Многие репозитории имеют по **3 тега одного и того же образа** (по ~270-310 MB каждый)
  — это исторические сборки (даты 2022-2023), скорее всего устаревшие.
- Часть тегов показывает **0 MB** (манифест недоступен / пустой) — например,
  `20230726144713` в pdb-sender, `20230626160834` в nn-calc — такие теги место
  не занимают.
- `minio/minio`, `minio/mc` — сторонние утилиты (75 MB, 48 MB).
- Репозитории `fipc-front`, `nn5-backend`, `pdb-front-end`, `recipe-front` — теги
  есть, манифесты недоступны (0 MB).

## Рекомендации

1. **Удалить устаревшие теги** в крупных репозиториях (fipc-*, ws-publisher,
   mes-sender и др.): оставить только актуальный, удалить старые исторические
   (2022-2023) — освободит ~2/3 от 13 GB (≈ 8-9 GB).
   ```
   curl -u user:pass -X DELETE https://ia-test-docker-docker.dp.nlmk.com/v2/<repo>/manifests/<digest>
   ```
   (нужен digest тега).

2. **Очистить 0-MB теги** (манифесты недоступны) — они не занимают место, но
   захламляют список.

3. **Удалить сторонние утилиты** `minio/minio` (75 MB) и `minio/mc` (48 MB), если
   не используются.

4. **Настроить политику ретенции** в Artifactory: автоматическое удаление тегов
   старше N дней, чтобы квота не росла.
